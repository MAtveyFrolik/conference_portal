# Конференции.РФ

Django-портал для бронирования помещений Всероссийских конференций по заданию ДЭ БУ 2027.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py seed_demo
.venv\Scripts\python manage.py runserver
```

Демонстрационный администратор:

- Логин: `Conf2027`
- Пароль: `Demo77`

## Что реализовано

- регистрация с проверкой логина, пароля, ФИО, телефона и email;
- авторизация, выход и профиль пользователя;
- создание заявки на помещение через выпадающий список;
- просмотр собственных заявок и отзыв только после статуса `Завершено`;
- административная панель с фильтрацией, карточками заявок и сменой статуса;
- адаптивная верстка под мобильный экран 390x844 px;
- локальные шрифты, изображения и стили без CDN.
